## 功能与评分
- [ ] 单词听写 cat → 首次计正确，输出cat标准答案在提交后。
- [ ] 单词听写 cat 给出“cta” → 计错误，提示字母顺序，不得误判正确。
- [ ] 句子 Don't / don't 大小写变体→ 不因大小写误判，词序/拼写仍需正确。
- [ ] p32 “It's an elephant.” 若学生写 “It's a elephant.” → 冠词差异计错，并解释a/an。
- [ ] 在提交之前，学生端聊天文字、提示、控制台响应和页面DOM不可获得正确答案原文（需通过访问控制真正隔离）。
- [ ] 两轮训练完成后再次打开，匿名用户学习记录仍在。
- [ ] 教师端统计不凭空生成班级人数、分数和提高百分比。
- [ ] 不支持真实口语发音评分时，不冒充已进行音素级发音评价。
- [ ] 所有TTS语音显示“AI合成示范音频”，不冒充教材配套原音。
- [ ] 当前版本可以从项目历史回滚，旧版未公开发布。
