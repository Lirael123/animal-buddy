# Animal Buddy 正确教材知识库 V2

正式教材：**Unit 3 Our animal friends，P26—P37**（用户提供《新版教材.zip》）。

> 禁用旧版《Amazing animals》知识库。本压缩包取代上一版，不要将两个版本合并导入。

## 文件和上传顺序
1. `01_教材知识库_核对版.md`：教材中可见事实+逐页引文+检索边界（首先导入）。
2. `02_词汇分层表.csv`：词汇条目、来源、所属板块、核心/拓展级别。
3. `03_听写固定题库.csv`：共 **47** 道候选题，**33** 道默认启用，其他默认停用（可经老师审核后启用）。相同题库还提供JSON。
4. `04_情境对话方案.json`：My pet、At the zoo两条对话任务与教材/改编区分。
5. `05_Agent系统提示词V2.txt`：用于替换现有角色提示词。
6. `06_扣子增量开发指令.txt`：发到扣子**开发对话框**，不是右侧学生测试聊天框。
7. `07_验收测试清单.md`：真实运行验收。
8. `08_教材页码核对索引.csv`：教材每一页的来源截图映射。
9. `00_清单.json`：文件统计。

## 核心约束
- 上传到扣子的开发聊天框 **并不意味着运行时自动拥有知识库**，须建立运行时数据检索和程序化评分。
- 课本截图只有教材内容，**没有教材配套原声**。系统生成的TTS属于AI合成示范音频，需明确标示。
- Part B p32的五个词是panda, monkey, tiger, elephant, lion；p31的fox、red panda和p33的giraffe属于其它层级。
- p34需听配套原声才能确定 Listen and circle 正确答案；不要虚构。
- 本包属于教材整理与技术指导素材，参赛须符合活动原创性、安全及真实应用证据要求。
